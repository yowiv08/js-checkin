## 功能

- New API、AnyRouter、AgentRouter 均可选择 Cookie / CK 或账号密码认证，兼容旧配置。
- New API 与 AnyRouter 密码模式先登录获取 session 和 User ID，再请求各自签到接口；登录成功不等于签到成功。
- 密码会话用于余额刷新和 API 令牌管理，认证失效时清理缓存，不隐式重新登录。
- 可视化编辑与 JSON 配置支持 `authMode`；切换认证方式清空另一模式的凭据。
- 更新开发依赖 source-map-js，修复已知安全问题。

## 兼容范围

- 密码模式支持返回 `data.id` 和 session Cookie 的模板。
- 验证码、二次验证、加密密码及仅返回 Bearer 令牌的登录版本暂不支持。
- AgentRouter 密码模式保留登录触发签到行为；Cookie 模式需要站点提供独立 `/api/user/checkin` 接口。
- 写请求不自动重试；超时或取消后先到站点核对。
