## 功能

- 新增「API 令牌」页面及账号卡片入口，支持 New API、AnyRouter、AgentRouter。
- 支持新建、编辑、复制密钥、启用、禁用和删除令牌。
- 可设置名称、分组、UTC+8 过期时间、有限/无限额度、模型限制和 IP 白名单。
- 金额与原始 quota 精确转换；密钥默认隐藏，按需读取。
- 余额刷新适用于全部站点；AgentRouter 使用已保存会话，不隐式登录或签到。

## 使用

- AgentRouter 令牌管理需要正常登录签到建立的、路径适用的会话。
- 写请求超时后不会自动重发；出现「待核对」时先刷新站点状态。
- 编辑时保留最新未修改额度；上游接口不保证并发消费与更新之间的原子性。
